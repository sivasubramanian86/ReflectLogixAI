# ReflectLogixAI UX & User Journeys

## Key User Flows

### 1. Daily Reflection Capture & Socratic Coaching
1. **Landing & Context**: User opens ReflectLogixAI and sees the 3-pane dashboard. Left pane shows historical timeline grouped by *Today*, *Yesterday*, *This Week*, and *Earlier*.
2. **Entry Authoring**: User types or speaks thoughts. Live waveform indicates voice recording. Real-time word counter and token estimator provide instant feedback.
3. **Detox & Privacy Toggles**: User can toggle **Detox Mode** (zero retention) or **Sensitive Entry** (encrypted, excluded from global aggregations).
4. **ADK Agent Orchestration**: In under 1.5 seconds, subagents extract mood valence, key themes, Socratic inquiry questions, and actionable micro-steps.
5. **Interactive Dialogue**: User converses with the **ReflectLogix Coach** in the center pane below the reflection card, digging deeper into emotional anchors.

### 2. Longitudinal Insights & Agentic RAG
1. **Affect Curves**: Right pane plots 30-day valence trajectory and average stress scores.
2. **Ask History**: User queries their entire journal history via Agentic RAG to uncover behavioral patterns over time.
3. **Micro-Action Tracking**: User checks off completed micro-actions, reinforcing cognitive agency and progress.
