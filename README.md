## ✨ Core Pillars & Navigation Modules

ReflectLogixAI organizes your holistic well-being and journaling into dedicated, high-performance workspaces:

### 1. 📖 My Journal (Timeline & Daily Canvas)
- **3-Pane Clean Interface**: Fast chronological timeline with multi-criteria filters (Today, Week, Month, Mood tags), word and token counters, location tagging, and privacy indicators.
- **Russell's Circumplex Affect Model**: Tracks continuous emotional coordinates (Valence: $-1.0$ to $+1.0$, Arousal: $0.0$ to $1.0$) and discrete stress intensity ($1$ to $10$).
- **Live 3D Voice Assistant (Nova)**: Hands-free vocal journaling with real-time waveform visualization, 3D avatar animation, and multi-turn audio streaming.

### 2. 🧠 Reflection Coach & Empathetic Chat (Dedicated Workspace)
- **Socratic Inquiry Engine**: Cognitive reframing, deep clarifying questions, and positive psychological anchors generated by the ADK Reflection Coach Agent.
- **Multi-Turn Empathetic Conversation**: Persistent multi-turn dialogue with Socratic reflection memory, contextual grounding, and empathetic listening.
- **Interactive Micro-Actions**: Actionable, time-bound behavioral nudges (Today / This Week) with persistent completion tracking.

### 3. 🎨 Media Studio (Multi-Modal GCS Hub)
- **Multi-Modal Cloud Ingestion**: Securely upload and process sticky notes, handwritten physical journals, 1-minute voice memos, and video logs stored in Google Cloud Storage (`gs://reflectlogix-media-genai-apac/`).
- **Gemini 2.5 Vision & Audio OCR**: Automatic extraction of unstructured thoughts, sentiment extraction, and automatic journal synthesis.

### 4. ⌚ Health & Wearables Hub
- **Biometric Wearable Sync**: Seamless integration with Google Health Connect, Samsung Health, Apple HealthKit, and Garmin.
- **Holistic Health Telemetry**: Correlates daily journal valence with resting heart rate, HRV (Heart Rate Variability), sleep stage architecture (Deep/REM), and daily step counts.

### 5. ⚡ Longevity & Lifestyle Flashcards
- **Spaced Repetition Micro-Habits**: Daily actionable flashcards spanning Circadian biology, Deep work pacing, Cortisol buffering, and Blue Zone lifestyle tips.

### 6. 🧭 Life & Goals Planner (Time-Saver & Future Predictor)
- **Predictive Trajectory Engine**: Projects daily, weekly, monthly, and yearly goal alignment and forecasts potential burnout bottlenecks.
- **Time-Saving Recommendations**: Proactive time-saving strategies to reclaim hours for mindful living and stress-free productivity.

### 7. 🔍 Deep Reflections (Agentic RAG)
- **"Ask My History" Semantic Search**: Hybrid vector retrieval via Cloud SQL / pgvector over multi-year reflection archives.
- **GraphRAG Entity Subgraph**: Traverses interconnected life entities (People, Places, Core Values, Habits, Emotions).

### 8. 📊 Insights & Trends
- **Longitudinal Affect Trajectories**: BigQuery rollup analytics calculating active consistency streaks, mood shift velocity, and stress mitigation patterns.

### 9. 🌐 18-Language Dynamic Localization (Indian & Global)
- **Zero-Latency Dynamic Switching**: Seamlessly adapts FAQ, About principles, reflection timeline cards, Socratic prompts, and Gemini responses across 18 native languages:
  - **Indian Languages:** Tamil (தமிழ்), Hindi (हिन्दी), Telugu (తెలుగు), Kannada (ಕನ್ನಡ), Malayalam (മലയാളം), Bengali (বাংলা), Marathi (मराठी), Gujarati (ગુજરાતી), Punjabi (ਪੰਜਾਬੀ).
  - **Global Languages:** English, Spanish (Español), French (Français), German (Deutsch), Japanese (日本語), Mandarin Chinese (中文), Arabic (العربية), Portuguese (Português), Russian (Русский).

## 🔒 Zero-Trust Security & DevSecOps

- **Strict Tenant Isolation**: All Firestore operations reside in `/users/{userId}/journals/{journalId}` guarded by `request.auth.uid == userId`.
- **Google Cloud Secret Manager**: Credentials (`GEMINI_API_KEY`, `GOOGLE_MAPS_API_KEY`, Webhooks) are securely accessed server-side and never exposed to the client bundle.
- **Detox Mode & Ephemeral Processing**: Zero-retention analysis mode with client-side PII scrubbing for sensitive personal thoughts.
- **SSRF & Outbound Data Sanitization**: Strict HTTPS validation blocking internal IP metadata ranges with append-only administrative audit logging.

## 🚀 Quick Start & Development

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/sivasubramanian86/ReflectLogixAI.git
cd ReflectLogixAI

# Install Node dependencies
npm install

# Install Python agent dependencies
pip install -r agents/requirements.txt
```

### 2. Environment Configuration
```bash
cp .env.example .env
# Set GEMINI_API_KEY from Google AI Studio / Vertex AI
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
